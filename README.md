# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on supermarket sales data using Python.

The analysis focuses on sales performance, customer behavior, payment methods, branch performance, product lines, and customer ratings.

---

## 🎯 Objectives

- Analyze overall sales performance
- Compare sales across cities and branches
- Analyze different payment methods
- Understand sales by gender
- Compare product line performance
- Analyze customer ratings
- Compare weekend and weekday sales
- Calculate branch-wise profit

---

## 📊 Analysis Performed

The project includes:

- Data loading and inspection
- Data cleaning
- Exploratory Data Analysis
- Sales analysis
- Customer analysis
- Payment method analysis
- Branch-wise analysis
- Product line analysis
- Customer rating analysis
- Data visualization

---

## 📈 Visualizations

The project generates visualizations for:

- Total Sales by City
- Sales by Gender
- Sales by Product Line
- Sales by Payment Method
- Payment Method Distribution
- Total Profit by Branch
- Average Rating by Branch
- Average Spending by Gender
- Total Sales by Product Line
- Weekend vs Weekday Sales

All generated charts are stored in the `plots/` folder.
