# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on supermarket sales data using Python.

The project includes data cleaning, statistical analysis, and visualization to understand sales performance, customer behavior, payment preferences, branch performance, and product sales.

---

## 📊 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
